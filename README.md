# Запуск приложения
- Заполните файл `.env` в соответствии с файлом `.env-example`.
- Соберите и запустите приложение: `make run`

# Запуск тестов
- Создайте тестовую БД: `make tests-db-up`
- Запустите тесты: `make tests-run`

# Документация API
Документация API (Swagger) доступна на ручке `/swagger/index.html`
